# ResumeAce 简历助手项目 README

## 一、项目概述
ResumeAce 是一款基于 Python 和 PySide6 开发的桌面应用程序，旨在通过自动化工具和 AI 辅助功能提升简历投递效率，提供简历优化、职位筛选、自动化投递及聊天咨询等功能。本项目包含图形界面、安卓设备控制、大模型交互等模块，适用于求职者快速匹配岗位并管理求职流程。


## 二、功能特性
### 1. **核心功能**
- **自动化职位投递**  
  通过 Airtest 和 Poco 库控制安卓设备，模拟人工操作实现BOSS直聘等求职平台的自动化职位筛选与投递，支持薪资范围、地区、关键词等条件过滤。
- **AI 聊天助手**  
  集成星火大模型，提供实时聊天咨询功能，可解答简历优化、面试技巧等问题，支持逐字显示效果。
- **用户界面**  
  - 抽屉式菜单：包含查看日志、加群交流、打开投递记录等功能。  
  - 主界面：提供文本输入框、进度条及操作按钮（连接设备、筛选条件、开始/停止任务等）。  
  - 可拖动调整窗口大小，支持圆角边框和透明背景。

### 2. **辅助功能**
- **配置管理**：支持自定义任务数量、薪资过滤、关键词等参数，配置文件自动保存至用户目录。  
- **数据记录**：将投递记录保存至 CSV 文件，存储于桌面“简历投递数据”文件夹。  
- **日志系统**：记录任务执行详情，支持日志文件查看。  
- **界面美化**：自定义样式表，统一字体和组件风格，提升用户体验。


## 三、技术架构
### 1. **主要技术栈**
- **编程语言**：Python 3.x  
- **GUI 框架**：PySide6（Qt6 官方 Python 绑定）  
- **自动化工具**：Airtest（安卓自动化测试框架）、Poco（UI 控件操作）  
- **大模型接口**：星火认知大模型 API  
- **数据存储**：JSON（配置文件）、CSV（投递记录）  
- **加密工具**：PyArmor（Python 文件加密）

## 四、使用说明
### 1. **环境搭建**
1. **依赖安装**  
   ```bash
   pip install -r requirements.txt
   ```
   需安装 PySide6、Airtest、poco、requests 等库。

2. **安卓设备连接**  
   - 开启手机开发者模式，通过 USB 连接电脑，允许 USB 调试。  
   - 在程序中点击“连接设备”，输入设备 IP 地址（若使用无线连接）。

3. **配置参数**  
   - 点击“筛选条件”按钮，设置职位关键词、薪资范围、地区等参数，支持中文输入。

### 2. **操作流程**
1. 打开程序，通过抽屉菜单查看日志或加群获取支持。  
2. 在主界面输入问题，点击“AI 聊天”按钮获取解答。  
3. 配置任务参数后，点击“开始任务”启动自动化投递，进度条显示任务完成度。  
4. 任务完成后，可在桌面“简历投递数据”文件夹查看 CSV 记录。

## 十、自动化任务逻辑
### 1. **流程概述**
1. **设备初始化**：通过 ADB 连接安卓设备，启动 BOSS直聘应用。  
2. **职位筛选**：根据配置的关键词和薪资范围，遍历列表页职位，过滤不符合条件的岗位。  
3. **简历投递**：点击岗位进入详情页，模拟点击“立即沟通”或“投递简历”按钮。  
4. **异常处理**：若控件查找失败或操作超时，自动回滚并记录错误日志。  
5. **数据记录**：将符合条件的岗位信息（名称、薪资、地点等）写入 CSV 文件。

### 2. **关键函数**
- `parse_page()`：解析职位详情页控件，提取岗位名称、描述、薪资等信息。  
- `filter_job_title()`：根据关键词过滤职位标题。  
- `execute_task()`：执行单个投递任务，包含异常捕获和回滚逻辑。  
- `swipe_left()`：模拟向左滑动操作，切换职位列表页。


## 十一、技术实现细节
### 1. **窗口拖动与缩放**
- **边缘检测**：通过 `_get_edges()` 方法检测鼠标位置是否位于窗口边缘（默认边缘宽度5像素）。  
- **拖动逻辑**：按住窗口顶部40像素区域时触发移动事件，更新窗口位置 `move(event.globalPosition() - movePosition)`。  
- **缩放逻辑**：根据鼠标所在边缘类型（如左、右、右下角等），调整窗口宽度和高度，包含最小尺寸限制（宽/高≥50像素）。

### 2. **安卓自动化控制**
- **Airtest 初始化**：在 `TaskWorker` 线程中调用 `auto_setup(__file__)` 初始化环境。  
- **Poco 控件操作**：通过 `poco("com.hpbr.bosszhipin:id/tv_job_name")` 定位控件，调用 `click()`、`swipe()` 等方法模拟用户操作。  
- **设备兼容性**：需确保安卓设备分辨率与控件定位适配，部分界面元素可能需根据不同设备调整坐标。

### 3. **AI 聊天实现**
- **线程处理**：聊天请求通过 `ChatThread` 线程异步处理，避免阻塞UI界面。  
- **流式输出**：通过 `StreamingChunkHandler` 逐字符接收大模型响应，实现实时显示效果。  
- **接口调用**：调用 `get_xinghuo_response()` 发送HTTP请求，处理JSON格式的返回结果。


## 十二、常见问题与解决方案
| 问题现象                     | 可能原因                                  | 解决方案                                                                 |
|------------------------------|-------------------------------------------|--------------------------------------------------------------------------|
| **设备连接失败**             | ADB服务未启动或IP错误                     | 检查USB连接或IP地址，重启ADB服务（`adb kill-server && adb start-server`）。 |
| **自动化任务无反应**         | 控件定位失败或应用界面异常                 | 调试 `parse_page()` 方法，确认控件ID是否正确，或手动操作应用至正确页面。     |
| **聊天功能无回复**           | 网络连接失败或API密钥过期                 | 检查网络连接，确认星火大模型API密钥有效，或更换API接口。                   |
| **CSV文件无法打开**          | 文件路径包含非法字符或权限不足             | 确保路径无中文或特殊符号，手动创建“简历投递数据”文件夹并赋予读写权限。     |
| **窗口无法缩放/拖动**        | 代码中边缘检测区域设置错误                 | 调整 `edge_size` 和 `move_event_height` 参数，重新编译程序。               |
